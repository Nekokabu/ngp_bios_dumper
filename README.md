# NGP / NGPC BIOS DUMPER

ネオジオポケット（モノクロ）とネオジオポケットカラーの内蔵BIOS（64KB）を、
カートリッジのフラッシュへ書き出すプログラムです。
書き出したカートを Neo Pocket Flash Masta でPCに吸い出し、付属スクリプトで切り出します。

作者: Nekokabu

## 仕組み

- BIOSはCPUのアドレス `0xFF0000-0xFFFFFF` にそのまま見えているので、普通に読めます。
- カートにはSRAMがないので、カートのフラッシュメモリに直接書き込みます。
- 書き込み先は機種ごとに分けています。1本のカートで両方のダンプを取れます。

| 実行した本体 | 書き込み先（カート内オフセット） | 出力ファイル |
| --- | --- | --- |
| ネオジオポケット（モノクロ） | `0x010000-0x01FFFF` | `ngp_bios.bin` |
| ネオジオポケットカラー | `0x040000-0x04FFFF` | `ngpc_bios.bin` |

- 判定は BIOS のシステム変数 `0x6F91`（0 = モノクロ機）で行います。
- ROMヘッダはモノクロ対応（`0x23 = 00h`）にしてあるので、どちらの本体でも起動します。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `biosdump.ngp` | ビルド済みROM（512KB）。これをFlash Mastaでカートに書き込む |
| `biosdump.asm` | ソース（TLCS-900/H アセンブリ） |
| `build.sh` | ビルドスクリプト |
| `extract.py` | カートのバックアップからBIOSを切り出すスクリプト（Python 3） |

## 使い方

1. Flash Masta で `biosdump.ngp` をカートに書き込みます。
   - カートの中身は上書きされるので、必要ならセーブデータなどを先にバックアップしてください。
2. カートをモノクロ機に挿して起動します。
   - 画面に「BIOS CRC xxxxxxxx」が出るので、メモしておきます。
3. 新しい電池（またはACアダプタ）であることを確認し、Aボタンを押します。
   - `WRITING` → `VERIFY OK` → `DONE. POWER OFF AND READ CART ON PC.` と表示されれば成功です。
   - 「CART CRC」は書き込み後にカートから読み直した値で、BIOS CRCと同じになるはずです。
4. 電源を切り、カートをカラー機に挿して同じ手順を繰り返します（片方だけでも構いません）。
5. Flash Masta でカート全体をPCにバックアップします。
6. 切り出します。

   ```
   python3 extract.py カートのバックアップ.ngp
   ```

   表示されるCRC32が、手順2で本体に出たCRCと一致すれば完了です。
   SHA-1も出るので、MAMEのハッシュ（`ngp` / `ngpc` ドライバ）とも照合できます。

## 画面の表示

| 表示 | 意味 |
| --- | --- |
| `HW: NGP MONO 00` / `HW: NGP COLOR 10` | 機種判定と `0x6F91` の値 |
| `BIOS CRC` | CPUから読んだBIOSのCRC32（zip / MAMEと同じ方式） |
| `ERASING...` | 書き込み先が空でなかったので消去中（2回目以降の実行時） |
| `WRITING xxxxxx` | 書き込み中のオフセット |
| `VERIFY OK` / `VERIFY NG n` | BIOSとカートの比較結果（NGは不一致バイト数） |
| `ERASE FAILED` / `WRITE FAILED` | フラッシュが応答しなかった |

## 動作確認の状況

- エミュレータ（Mednafen系 NGPコア、BIOSはHLE）で、モノクロ・カラー両方の経路を確認済みです。
  書き込まれた64KBがエミュレータ内部のBIOSイメージとバイト単位で一致し、画面のCRCとPC側のCRCも一致しました。
- **実機では未確認です。** 特に次の2点はエミュレータでは再現できません。
  - **消去処理**：エミュレータは消去コマンドを再現しないため未テストです。
    初回はROMイメージの該当領域が `FFh`（消去済み）なので、消去は走りません。
  - **フラッシュの実際の書き込み時間**：実機では1バイトあたり数十µsかかります。
    64KBで数秒です。
- Flash Masta が `FFh` の領域を書き込み時に省略する場合でも、
  プログラム側で空き確認をして、必要なら消去してから書き込みます。

## 実装メモ

- 書き込みと消去のルーチンはRAM（`0x5000`）にコピーし、割り込み禁止で実行します。
  動作中のフラッシュは読み出しができず、カート上のコードを実行できないためです。
- 書き込みは256バイトずつに分けています。合間に割り込みを戻すので、VBlankが長時間止まりません。
- ウォッチドッグ（`0x6F` に `4Eh`）は、待ちループの中でもクリアしています。
- フラッシュのコマンドは `AA@5555 / 55@2AAA` の標準的なシーケンスです。
  - 書き込み：`A0`
  - ブロック消去：`80 / AA / 55 / 30`
- BIOSのフラッシュ関数（`VECT_FLASHWRITE` など）は使っていません。
  カートサイズ判定（`0x6C58`）に依存しないためです。

## ビルド

Macro Assembler AS（`asl` と `p2bin`）を使います。単体のコマンドラインツールで、
Windows / Linux / macOS で動きます。

```
./build.sh
# asl が PATH にない場合
ASL=/path/to/asl P2BIN=/path/to/p2bin ./build.sh
```

入手方法は `build.sh` の先頭に書いてあります。
